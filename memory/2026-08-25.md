### 執行中遇到的坑

1. **PowerShell `2>$null` 干擾 stdout**：JSON pipe 為空，改用 `subprocess.run(capture_output=True)`
2. **PowerShell `>` 重定向產生 UTF-16 BOM**：Python `json.load` 失敗，同上改用 subprocess
3. **`python -m` 載入 site-packages 舊版**：需用 `PYTHONPATH=src` 強制本地優先
4. **`git_commit` 工具省略 `files` 時執行 `git add -A`**：意外帶入 untracked 檔案，需 `git reset --soft` + `git reset HEAD --` 修正後用 `exec_command` 重新提交
5. **PowerShell 5.1 不支援 `utf8NoBOM`**：改用 `[System.IO.File]::WriteAllText()` 寫 UTF-8 無 BOM
