# skill-safety-guard Web 界面設計規格

> **用途**：CLI 之外的 Web 界面（日後轉移到伺服器後端時應用）
> **版本**：v1.0（設計稿）｜ **日期**：2026-08-19
> **配套原型**：`demo/web-ui/index.html`（可交互 HTML 原型）
> **設計方法**：interface-design（架構/流程/組件）+ frontend-design（視覺 token）

---

## 0. 設計摘要

### Intent（誰在用、做什麼、什麼感覺）

| 維度 | 內容 |
|------|------|
| **用戶** | 個人開發者，看到一個想安裝的第三方 Skill/MCP（GitHub URL），打開網頁粘貼目標，5 分鐘內決定「裝不裝」 |
| **核心任務** | 粘貼目標 → 一鍵掃描 → 讀懂結論 → 決定安裝 / 不裝 / 標記誤報 |
| **感覺** | 「體檢報告」：冷靜、可信、權威但不嚇人。不是 SOC 監控室的陰暗螢光綠，不是花俏 SaaS——是**拿到報告那一刻就能看懂**的安全檢查 |

### 設計方向：體檢報告 × 審計台

- **信號三色只屬於結果**：綠=可安裝、黃=需複查、紅=拒裝。這是產品世界的天然語言，不刻意迴避，但**絕不用於裝飾**。
- **動作色 = 守護青**：掃描/執行按鈕用青色（`#0E7490`），與結果信號色嚴格分離——綠按鈕會讓用戶誤以為「掃描=安全」。
- **墨色側邊欄**：深墨藍（`#0B1220`）代表審計台的權威，內容區紙白（`#F7F8FA`）代表體檢報告。
- **簽名元素**：風險決策大徽章（見 §6.6）——每次掃描只有一個結論，讓它贏。

## 1. 信息架構與頁面層級

```
Web 應用（SPA，側邊欄 + 主內容區）
│
├── 🛡️ 掃描工作台（首屏 / 殺手場景）
│   ├── 掃描輸入區（目標 + 模式 + 一鍵掃描）
│   ├── 掃描過程（進度 / 取消）
│   ├── 掃描結果摘要（決策大徽章 + 統計）
│   ├── 發現項表格（篩選 / 批量操作）
│   └── 掃描結論區（三部分：結論 / 說明 / 數字卡片）
│
├── 🕘 掃描歷史
│   ├── 歷史列表（表格）
│   └── 歷史詳情（= 掃描工作台的結果視圖，只讀）
│
├── 📡 漏洞情報
│   ├── 數據源狀態卡片（OSV/AVID/CAIVD/內置庫）
│   └── CVE 列表（表格 + 篩選）
│
├── 📚 規則庫
│   ├── 規則類別總覽（9 類 / 181 條）
│   └── 規則明細（彈出層）
│
├── 🎯 誤報管理
│   ├── 誤報反饋表單
│   └── 白名單列表（本地自定義）
│
└── ⚙️ 設置 / 許可證（側邊欄底部入口）
    ├── 許可狀態（Free / Pro + 剩餘額度）
    └── 偏好設置（漏洞更新頻率、輸出格式、代理）
```

**層級原則**：導航 ≤ 2 層。規則庫與誤報管理是「事後治理」視圖，不搶掃描工作台的焦點。設置永遠在側邊欄底部，不進主導航。

## 2. 核心操作流程（殺手場景端到端）

### 2.1 主鏈路：掃描 → 決策（用戶 80% 時間在這條路上）

```
[1] 粘貼目標              [2] 一鍵掃描           [3] 讀結論          [4] 決定
┌─────────────┐       ┌──────────────┐       ┌───────────┐     ┌──────────┐
│ GitHub URL  │  ⏎   │ 掃描進行中     │       │ 大徽章     │     │ ✅ 安裝   │
│ ./my-skill  │ ───► │ 掃描線動效     │ ───►  │ SAFE A 級  │ ──► │ 👀 複查   │
│ 粘貼內容     │       │ 可取消        │       │ + 統計     │     │ 🚫 不裝   │
└─────────────┘       └──────────────┘       └───────────┘     └──────────┘
                                                      │
                                              [4b] 深入複查（CAUTION/DANGER 時）
                                                      ▼
                                         發現表格 → 篩選高嚴重度
                                         → 點開詳情（命中代碼 + 規則建議）
                                         → 標記誤報 / 下載 JSON/SARIF / 複製結論
```

**設計要求**：
- 步驟 1→2 零摩擦：粘貼 URL 後 Enter 即掃描，模式可事後切換
- 步驟 3 是視覺焦點：大徽章讓結論在 1 秒內被讀到，不靠滾動
- 步驟 4b 是唯一的深度路徑，表格交互效率在此決定成敗（見 §5.1）

### 2.2 次鏈路：誤報治理

```
發現表格 → 勾選發現 → 「標記為誤報」
         → 彈出表單（可選填原因）
         → 寫入本地白名單 → 即時重掃該發現（從表格消失）→ 統計更新
```

### 2.3 管理鏈路：許可證 / 漏洞情報

```
側邊欄底部 → 許可證 → 顯示 Free 剩餘次數 / Pro 到期
          → 粘貼 Pro Key → 激活
漏洞情報 → 查看各源狀態 → 手動更新（--update-vulns 的 Web 化）
```

## 4. 頁面詳述

### 4.1 掃描工作台（首屏）

**佈局（從上到下）**：

```
┌──────────────────────────────────────────────────────┐
│ 頁頭：掃描工作台（h2 22px/700）+ 說明文字（muted）      │
├──────────────────────────────────────────────────────┤
│ 掃描輸入區（surface 卡片，內嵌式）                     │
│  ┌──────────────────────────────────────────────┐   │
│  │ 目標輸入框（大，內嵌深於卡片）                    │   │
│  │ [📋 粘貼示例]  模式：默認 ▾   [開始掃描 ⚡]     │   │
│  └──────────────────────────────────────────────┘   │
│  提示行：支持 GitHub URL / 本地路徑 / 粘貼內容          │
├──────────────────────────────────────────────────────┤
│ 結果區（掃描後出現）                                  │
│  ┌──────────────────────────────────────────────┐   │
│  │ 決策大徽章（左）+ 統計卡（右，3 個）             │   │
│  └──────────────────────────────────────────────┘   │
│  發現項表格（見 §5.1）                               │
│  掃描結論區（三部分，與 CLI 報告對齊）                 │
└──────────────────────────────────────────────────────┘
```

**掃描輸入區設計要點**：
- 輸入框是本頁焦點：大（48px 高）、內嵌填充（比卡片深）、聚焦時青色光環
- 模式選擇：Segmented Control（默認 / Pi 全局 / 完整 / Pro），非下拉，減少一次點擊
- 「開始掃描」是唯一主按鈕（守護青，48px 高），Enter 同義
- 掃描進行中：按鈕變「取消」，輸入框鎖定，結果區顯示掃描線動效 + 已掃文件計數

### 4.2 掃描結果：決策大徽章 + 統計

```
┌─────────────── 卡片 ───────────────┐
│  ┌─ 徽章 ─┐   ┌ 統計 ──────────┐  │
│  │   DANGER│   │ 文件數  425     │  │
│  │   F 級   │   │ 有效發現 8      │  │
│  │  🚫 拒裝  │   │ 誤報排除 0      │  │
│  └─────────┘   │ 規則命中 8/181  │  │
│  目標：github.com/user/repo        │
│  時間：2026-08-19 10:32 · 3.2s     │
└────────────────────────────────────┘
```

- 徽章 160px 見方，信號色實底 + 白字，大徽章字 28px/800 + 等級字 64px 等寬（tabular）
- 統計數字一律 `font-variant-numeric: tabular-nums`，防跳動
- 目標/時間/耗時為輔助元信息，縮小 + muted，不搶焦點

### 4.3 掃描歷史

- 表格：目標 | 模式 | 決策徽章（小）| 風險等級 | 發現數 | 誤報數 | 時間 | 操作（查看/導出）
- 行點擊進入詳情（只讀的結果視圖）
- 篩選：決策（SAFE/CAUTION/DANGER）、時間範圍、搜索目標關鍵詞
- 空狀態：🕘 「還沒有掃描記錄 — 粘貼一個 GitHub URL 開始第一次檢查」

### 4.4 漏洞情報

- 頂部：數據源狀態卡（OSV.dev ✅ / AVID ✅ / CAIVD ℹ️ 人工 / 內置庫 🕐 3 天前更新）+ 「立即更新」按鈕
- CVE 表格：CVE ID（等寬）| 嚴重度 | 影響組件 | 影響版本 | 來源 | 狀態
- 篩選：嚴重度、來源、搜索 CVE ID/組件名

### 4.5 規則庫

- 9 類卡片網格（每類：圖標 + 名稱 + 規則數 + 嚴重度分佈 mini bar），點擊進入該類規則列表
- 規則行：規則 ID（等寬）| 名稱 | 嚴重度 | 置信度 | 命中示例（truncate）
- 點行彈出層：完整 pattern、description、remediation、白名單建議

### 4.6 誤報管理

- 誤報反饋：表單（見 §5.4）
- 白名單列表：規則 ID | pattern | 類型（pattern/path）| 原因 | 操作（刪除/停用）
- 批量：多選 → 停用 / 刪除

## 5. 組件規範（重點）

### 5.1 數據表格（發現項表格 — 全應用最高頻組件）

**列定義**（按重要度排序，可隱藏列）：

| 列 | 內容 | 寬度策略 |
|----|------|---------|
| 嚴重度 | 色點 + 標籤（🔴 Critical/🟠 High/🟡 Medium/🟢 Low）| 固定 96px |
| 規則 ID | 等寬字體，如 `shell-curl-bash` | 固定 180px |
| 類別 | 9 類圖標 + 名稱 | 固定 140px |
| 位置 | `docs/PACKAGE_INTRO.md:22` | 彈性（truncate，hover 顯示全路徑）|
| 命中內容 | 命中片段，等寬，語法高亮 | 彈性最大 |
| 置信度 | 🔴高/🟡中/🟢低（小徽章）| 固定 72px |
| 誤報 | ✅ 誤報 / — | 固定 72px |
| 操作 | 詳情 ▾ / 標記誤報 | 固定 96px |

**設計要求**：
- 表頭 sticky，文字 12px/600/muted，無序號列（序號是裝飾）
- 行高 44px，hover 背景微亮，點行展開詳情（行內展開，不跳頁）
- 嚴重度排序默認：Critical → High → Medium → Low → 誤報
- 表格底：頁碼 + 「每頁 50/100/250」+ 總數（tabular）
- 列太多時 horizontal scroll，第一列（嚴重度）sticky left

**行內展開（詳情）**：
```
命中代碼（等寬，深色背景代碼塊）
規則建議（remediation）
[標記為誤報] [複製 JSON] 
```

### 5.2 篩選器（表格上方工具列）

```
[🔍 搜索…__________] [嚴重度 ▾] [類別 ▾] [置信度 ▾] [✓ 僅看有效] [清除]  |  [批量操作 ▾]
```

- 工具列：28px 高，與表頭同一視覺層（不另外做卡片）
- 篩選器 = 自定義下拉（多選 + 複選框），非原生 select（要可多選、可清除）
- 活動篩選數顯式顯示：`嚴重度:2 · 類別:1` 可單獨移除
- 「僅看有效」是**默認開**的開關（誤報預設摺疊，符合誤報率>檢出率理念）
- 篩選結果即時反映到統計卡（數字連動）

### 5.3 狀態展示

| 狀態 | 表現 | 場景 |
|------|------|------|
| **決策狀態** | 大徽章（SAFE 綠/CAUTION 黃/DANGER 紅）| 結果摘要 |
| **小決策** | 12px 圓角小徽章（表格/歷史列表用）| 列表行 |
| **掃描中** | 掃描線光柵動效（橫向掃過 + 已掃 N 文件實時計數）| 輸入區下方 |
| **加載** | 骨架屏（表格：5 行灰色 shimmer）| 歷史/漏洞/CVE 載入 |
| **空狀態** | 圖標 + 標題 + 行動按鈕（不顯示「無數據」乾巴巴文字）| 所有列表 |
| **錯誤** | 內聯警示條（黃）：目標無法解析 / 網絡超時 + 重試按鈕 | 掃描失敗 |
| **許可狀態** | 側邊欄內聯 `Free 2/5`；用盡 → 黃色 + 「升級」連結 | 全局 |
| **漏洞庫狀態** | 卡片內：✅ 正常 / ⏭ 未更新（N 天前）/ ℹ️ 人工查詢 | 漏洞情報頁 |

### 5.4 表單

| 表單 | 欄位 | 交互 |
|------|------|------|
| **掃描目標**（主表單）| 目標（URL/路徑/paste 切換）、模式（Segmented）| Enter 提交；錯誤內聯 |
| **誤報反饋** | 規則 ID（預填只讀）、目標（預填）、原因（可選 textarea）、類型（pattern/path）| 提交後 toast「已記錄，感謝反饋」|
| **許可激活** | Pro Key（等寬字體輸入，貼上自動 trim）| 成功 → 側邊欄即時變 Pro |
| **白名單添加** | 規則 ID（下拉）、pattern/path、原因（必填——強制用戶寫 why，防垃圾）| 添加後立即生效 |

**規範**：標籤 13px/500 置於輸入上方（非 placeholder）；輸入框內嵌填充（比背景深一檔）；聚焦青色光環 2px；錯誤紅色文字 + 紅色邊框，錯誤訊息與欄位同區顯示。

### 5.5 批量操作

- **觸發**：表格多選（複選框列，勾 ≥1 時浮出操作欄，替換工具列右側）
- **浮出欄**：`已選 3 項 [批量標記誤報] [批量導出 JSON] [清除選擇]`
- **批量標記誤報**：二次確認（`確定將 3 項標記為誤報？可隨時在白名單中移除`）
- **批量導出**：單一 JSON 文件，含選中發現的完整上下文
- 全選 = 表頭複選框；分頁切換後保留選擇（表格上方顯示 `已選 N 項（跨頁）`）

### 5.6 反饋狀態（全局）

- **Toast**：右上角滑入，250ms，自動消失（3s）；成功=綠勾、失敗=紅叉、信息=青
- **內聯錯誤**：表單欄位下方，不彈窗（彈窗打斷流程）
- **二次確認**：僅破壞性操作（刪白名單 / 批量標記），用 `<dialog>` 原生元素

## 6. 視覺與設計 Token（frontend-design 規範）

### 6.1 設計方向

**「體檢報告 × 審計台」**：冷靜紙面承載權威結論。信號三色 = 結果語義（唯一允許的飽和色），守護青 = 動作，墨色 = 結構，紙白 = 內容。等寬數字貫穿全局（審計台的儀器感）。

### 6.2 色彩 Token

| Token | 值 | 用途 |
|-------|-----|------|
| `--ink-900` | `#0B1220` | 側邊欄背景、主文字 |
| `--ink-700` | `#334155` | 次要文字 |
| `--ink-500` | `#64748B` | 輔助文字（muted）|
| `--ink-400` | `#94A3B8` | 禁用/占位 |
| `--paper` | `#F7F8FA` | 頁面背景（體檢紙）|
| `--surface` | `#FFFFFF` | 卡片表面 |
| `--line` | `rgba(11,18,32,0.08)` | 分隔線/邊框（低透明度，柔和）|
| `--scan` | `#0E7490` | 守護青：主按鈕、聚焦環、掃描動效（動作色）|
| `--scan-weak` | `#E0F2FE` | 青的淺底（選中背景、徽章弱化）|
| `--safe` | `#15803D` | SAFE / 成功 |
| `--safe-weak` | `#DCFCE7` | 綠淺底 |
| `--caution` | `#B45309` | CAUTION / 警告 |
| `--caution-weak` | `#FEF3C7` | 黃淺底 |
| `--danger` | `#B91C1C` | DANGER / 錯誤 |
| `--danger-weak` | `#FEE2E2` | 紅淺底 |

**規則**：一色一義，不混用。綠永不作按鈕色（避免「掃描=安全」誤導）。深色側邊欄內信號色降飽和一檔（`#22C55E`/`#F59E0B`/`#EF4444`），保證暗底可讀。

### 6.3 字體

| 角色 | 字體 | 用途 |
|------|------|------|
| 數字/代碼 | **JetBrains Mono**（fallback: ui-monospace）| CVE ID、規則 ID、統計數字、命中代碼、許可 Key |
| 正文 | **Inter** + **Noto Sans SC** | 界面文字、表格 |
| 徽章大字 | JetBrains Mono 800 | 等級字（A-F）、決策大字——審計儀器感 |

**字階**（基準 14px，比率 ~1.25）：

```
caption 11/500  ·  body 14/400  ·  label 13/500
h4 16/600  ·  h3 18/600  ·  h2 22/700  ·  h1 28/700  ·  display 64/800（僅徽章）
```

**規則**：權重 + 顏色做層級（14px 三檔：600/主色、500/次色、400/muted）；等寬數字全用 `font-variant-numeric: tabular-nums`。

### 6.4 間距 / 圓角 / 陰影

| Token | 值 |
|-------|-----|
| 間距基準 | 8px（微 4 / 組件 8-12 / 區塊 16-24 / 頁面 32）|
| 圓角 | 4px（輸入/按鈕）· 6px（卡片）· 8px（彈出層/表格行展開）· 12px（大徽章）|
| 陰影策略 | **柔和陰影**（唯一策略，不混用）：`0 0 0 1px rgba(11,18,32,.06), 0 1px 2px rgba(11,18,32,.06), 0 2px 6px rgba(11,18,32,.05)` |
| 密度 | 工具台緊湊：表格行 44px、工具列 28px、導航 40px |

**同心圓角**：卡片 6px + 內部輸入 4px（外 = 內 + padding）。

### 6.5 組件規格

| 組件 | 規格 |
|------|------|
| **主按鈕**（開始掃描）| 48px 高 · 12px/20px padding · 6px 圓角 · 14px/600 白字 · 背景 `--scan` · hover 加深 5% · active `scale(0.98)` |
| **次按鈕** | 36px 高 · 背景 `--surface` · 1px `--line` 邊框 · hover 背景微灰 |
| **危險按鈕** | `--danger` 底白字，僅用於破壞性確認 |
| **輸入框** | 48px（主表單）/36px（表格工具列）· 背景比卡片深一檔 `#F1F5F9`（內嵌感）· 聚焦 2px `--scan` 光環 |
| **Segmented Control** | 36px 高，選中項白底 + 細陰影（iOS 式），非彩色 |
| **下拉** | 由 headless primitive（Radix/Listbox）構建：鍵盤導航、Esc 關閉、點外關閉、多選複選框 |
| **表格** | 行 44px · 表頭 12px/600/muted sticky · hover `rgba(11,18,32,0.03)` · 分隔線僅水平（`--line`）|
| **決策小徽章** | 12px/600 白字 · 圓角 4px · 實底信號色（表格/列表）|
| **Toast** | 右上 · 260px 寬 · 12px/16px padding · 6px 圓角 · 滑入 200ms · 3s 自動消失 |
| **彈出層** | 圓角 8px · 陰影加一層 · `transform-origin` 對齊觸發點 · 150-200ms |

### 6.6 簽名元素：風險決策大徽章

```
┌──────────────┐
│   🛡️         │   ← 護盾標誌（信號色）
│  DANGER      │   ← 28px/800 白字
│     F        │   ← 64px/800 JetBrains Mono（等寬儀器感）
│  拒絕安裝    │   ← 14px/500 白字（決策文案）
└──────────────┘
  背景：信號色實底（綠/黃/紅），內部 1px 同色系白 10% 描邊
  底部：掃描完成光柵線（1px 白 15%，只出現一次，不循環）
```

**只屬於本產品**：任何其他產品不會有一個「給你一個明確安裝結論」的巨型三色徽章。這是掃描結果的**唯一主角**，頁面上其他元素都為它讓路。

### 6.7 動效

- 掃描中：掃描線橫掃光柵（背景紙白上青線，1.2s 循環）+ 已掃文件數即時跳動（tabular）
- 徽章出現：從 `scale(0.95)+opacity 0` 到 1（250ms，ease-out），不從 scale(0)
- 表格行展開：展開 150ms，色調/透明度過渡
- 按鈕按壓：`scale(0.98)`（>0.95 下限）
- 全部 `transition` 只動 `transform` + `opacity`
- `prefers-reduced-motion`：保留透明度過渡，關閉掃描線與縮放

## 7. 響應式與可訪問性

- **斷點**：≥1200px 側邊欄展開；<1200px 側邊欄收縮為 64px 圖標欄；<768px 底部導航欄（5 項）
- 表格 <768px：列摺疊為卡片（位置/命中並入詳情），嚴重度/規則 ID/操作 三列保留
- 鍵盤：全組件可 Tab 到達、可見 focus 環（2px `--scan`）、Esc 關閉彈出層
- 對比度：正文 ≥ 4.5:1；決策大徽章白字 ≥ 4.5:1
- 命中目標 ≥ 40×40px（複選框用偽元素擴大熱區）
- 語義：表格用 `<table>`、彈出層用 `<dialog>`、segmented 用 radio group
