## 一、开发优先级原则

本文档按**两个维度**对功能进行排序：

| 优先级 | 维度 | 说明 |
|--------|------|------|
| **P0（最高）** | 核心差异化功能 + 易实现 | 这是MVP必须包含的，且AI编程工具能高效生成 |
| **P1（高）** | 核心功能 + 中等难度 | MVP后第一轮迭代加入 |
| **P2（中）** | 增强功能 + 需要较多人工调试 | 产品化阶段加入 |
| **P3（低）** | 高级功能 + 复杂度高 | 商业化扩展阶段加入 |

**核心开发理念**：
> 优先交付用户**能感知到价值**的功能，而非完美的功能。

## 七、利用AI编程工具的开发策略

### 每个任务的AI使用方式

| 任务类型 | AI使用方式 | 人工介入点 |
|---------|-----------|----------|
| **正则表达式生成** | 描述需求 → AI生成 → 直接使用 | 验证检出率和误报率 |
| **JSON/YAML解析** | 描述数据结构 → AI生成 → 微调 | 确认字段映射正确 |
| **Shell命令调用** | 描述命令 → AI生成 → 使用 | 确认路径和参数正确 |
| **报告格式化** | 描述格式需求 → AI生成 → 使用 | 确认美观度和可读性 |
| **API调用（MCP SDK）** | 描述需求 → AI生成 → 调试 | 调试连接问题 |
| **许可证密钥系统** | 描述逻辑 → AI生成 → 整合 | 安全审查 |
| **端到端测试** | 手动构造测试用例 → AI辅助调试 | 验证功能完整性 |

### 推荐AI工具组合

| 用途 | 推荐工具 | 原因 |
|------|---------|------|
| **代码生成** | Cursor / Claude Code | 上下文理解强，能生成完整的项目代码 |
| **正则规则** | Claude Code 或 ChatGPT | 正则表达能力优秀 |
| **调试辅助** | Pi Agent 自身 | 理解Pi生态的最优工具 |
| **文档生成** | 任何LLM | 结构化输出能力成熟 |
