# 打賞方案（GitHub 掛載贊助）

> **需求**：GitHub 項目掛打賞，費率 0%，支持全球人員資助，收入打入支付寶或微信
> **日期**：2026-08-19 ｜ **結論**：單平台無法同時滿足三約束，採用**雙通道組合**
> **誠實評估**：0% + 全球 + 直接入支付寶/微信 無法 100% 同時達成，此方案為最接近路徑（~80% 達標）

---

## 一、需求拆解（三個約束的真實衝突）

| 約束 | 滿足它的平台 | 卻犧牲了 |
|------|------------|---------|
| **0% 費率** | GitHub Sponsors（個人 0%）、Ko-fi（捐贈 0%）| 綁定 Stripe/PayPal 海外收款，**無法直接入支付寶/微信** |
| **全球可贊助** | 上述平台 + Stripe/PayPal 通道 | 大陸收款需海外帳戶（✅ **澳門可辦**，見 §三）|
| **入支付寶/微信** | 愛發電、個人收款碼 | 愛發電 6%+1% 費率；收款碼僅大陸用戶可用 |

**本質**：能 0% 全球收款的平台都用 Stripe/PayPal（大陸個人開不了，**但澳門可開**，見 §三）；能入支付寶/微信的通道都有費率或地區限制。

---

## 二、平台對比（查證 2026-08）

| 平台 | 平台費 | 支付處理費 | 全球 | 提現到支付寶/微信 | 備註 |
|------|--------|-----------|------|------------------|------|
| **GitHub Sponsors** | **0%**（個人）| 贊助者承擔 | ✅ | ✅ **澳門可收款**（Macao SAR 在官方支持列表）| 組織帳戶最高 6%；最權威，顯示在 repo 首頁 |
| **Ko-fi** | **0%**（捐贈）| Stripe 扣 2.9%+$0.3 | ✅ | ❌ 僅 Stripe/PayPal | 可掛在 repo 的 Sponsors 按鈕 |
| Buy Me a Coffee | 5% | Stripe/PayPal | ✅ | ⚠️ 部分支持 Alipay（不穩定，以官方為準）| 知名度高但收費 |
| **愛發電 (afdian)** | **6%** | +1% 支付渠道費 | 偏大陸 | ✅ **支付寶/微信提現** | 支持會員制/留言，粉絲留存好；大陸主流 |
| **支付寶/微信個人收款碼** | **0%** | 0% | ❌ 僅大陸用戶 | ✅ 直接入帳 | 最簡單；全球用戶無法使用 |
| Airwallex / WorldFirst | 0.3-1% 匯兌 | — | ✅ | 結匯後可提現 | 跨境收款合規工具，需認證 |

> ⚠️ 費率可能隨時變動，落地前以各平台官方頁面為準。

## 三、推薦方案：雙通道組合

```
GitHub 項目
│
├─ 通道 A：全球贊助（0% 費率）
│    GitHub Sponsors 按鈕（repo 首頁原生顯示）
│    └─ 前提：✅ **澳門證書可辦 Stripe 收款**（GitHub Sponsors 官方支持 Macao SAR）
│    └─ 資金流向：贊助 → Stripe → **澳門銀行** →（自行結匯）→ 支付寶/微信
│    └─ 替代（暫時無 Stripe 時）：Ko-fi（0% 平台費）+ Payoneer/WorldFirst 結匯
│
└─ 通道 B：大陸贊助（0% 費率，直接入帳）
     README 打賞區放支付寶/微信個人收款碼圖片
     └─ 資金流向：掃碼 → 直接入支付寶/微信（0%）
     └─ 進階：愛發電頁面（6%+1%，換來會員制/留言/關注功能）
```

**組合後的費率**：大陸用戶走收款碼 = **0%**；全球用戶走 Sponsors = **0% 平台費**。整體最接近「0% 打賞」訴求。

## 三、澳門方案（你已有澳門證書 → 全球 0% 通道可打通）

**官方確認**（GitHub Docs，2026-08 查證）：GitHub Sponsors 收款支持地區列表包含 **Macao SAR**。

| 項目 | 說明 |
|------|------|
| **收款方式** | 註冊 GitHub Sponsors 個人帳戶 → Stripe Connect 收款 → 綁定**澳門銀行帳戶**提現 |
| **費率** | 個人帳戶 **0% 平台費**（贊助者承擔信用卡處理費）；組織帳戶最高 6% |
| **資金流向** | 贊助 → GitHub → Stripe → 澳門銀行 → 自行結匯 → 支付寶/微信（或留澳門帳戶） |
| **付費頻率** | GitHub 每月 22 日付款（官方機制） |
| **與收款碼並存** | 全球贊助走 Sponsors（0%），大陸用戶仍可直接掃 README 收款碼（0%）| 

**動作**：
1. 到 https://github.com/sponsors 用澳門證件/銀行資料申請收款人
2. Stripe Connect 綁定澳門銀行帳戶（詳見下方「Stripe Connect 綁定澳門銀行帳戶具體步驟」）
3. 等待審核通過後，repo 的 Sponsor 按鈕即可收款

## 三-b、Stripe Connect 綁定澳門銀行帳戶——具體步驟（官方流程）

> 來源：GitHub Docs「Setting up GitHub Sponsors」+ Stripe 官方文檔（2026-08 查證）
> ⚠️ 硬性要求：**居住地 = 銀行帳戶所在地區**（你以澳門身份申請 → 銀行帳戶必須是澳門銀行帳戶）

### 第一階段：GitHub Sponsors 申請（先於 Stripe）

```
1. 登入 GitHub → 右上角頭像 → Your sponsors
2. 點「Get sponsored」→ 選擇個人帳戶
3. 填寫聯繫信息（姓名、地址、電話）
   └─ 國家/地區選「Macao SAR」
4. 選擇收款方式：
   └─ 銀行帳戶（Stripe Connect）← 選這個
   （fiscal host 只能在註冊時設定，事後不可改，勿選錯）
5. 閱讀並同意 GitHub Sponsors 附加條款 → Submit
6. ⚠️ 先開 2FA（雙重認證）：GitHub 強制要求，未開無法成為收款人
```

### 第二階段：審核通過後，創建 Stripe Connect 帳戶

```
1. GitHub Dashboard → 左側「Stripe Connect account」
2. 點「Create your account」→ 跳轉 Stripe
3. 填寫 Stripe Connect 註冊信息：
   └─ 身份：與 GitHub 申請時完全一致（姓名/出生日期/地址）
   └─ ⚠️ 身份信息提交後難以修改，務必一次填對
4. 提交後等待 Stripe 審核（通常幾小時到幾天）
```

### 第三階段：在 Stripe 綁定澳門銀行帳戶

```
1. 登入 Stripe Dashboard → 左側 Settings → Payouts（提現）
2. 點「Add bank account」→ 國家選「澳門 (Macao/MO)”
3. 輸入銀行資料：
   └─ SWIFT/BIC 代碼（8 或 11 位）
   └─ 銀行帳號（澳門無 IBAN，用帳號即可）
   └─ 帳戶持有人姓名（須與 Stripe 身份一致）
4. 驗證方式（二選一）：
   └─ 即時驗證（部分銀行支持，幾分鐘）
   └─ 小額存款驗證（Stripe 匯 2 筆小額，輸入金額確認）
5. 驗證通過 → 提現目標設定完成
```

### 澳門常見可綁定銀行（以 Stripe 下拉列表實際支持為準）

| 銀行 | SWIFT | 備註 |
|------|-------|------|
| 大西洋銀行 BNU | BNULMOMX | 澳門發鈔行之一 |
| 大豐銀行 | TFBLMOMX | 本地銀行 |
| 中國銀行澳門 | BKCHMOMX | 中資，大陸提現方便 |
| 工商銀行澳門 | ICBKMOMX | 中資 |
| 澳門國際銀行 | BIMKMOMX | 本地銀行 |

> ⚠️ 以 Stripe「Add bank account」頁面搜索結果為準；若你的銀行不在列表，需聯繫 Stripe 支持或換一家。
> 中資銀行（中銀/工銀澳門）→ 後續結匯回支付寶/微信更順。

### 第四階段：稅務與上線

```
1. 提交稅表：Dashboard → Overview → tax forms
   └─ 非美國居民填 W-8BEN（澳門身份適用）
2. 點「Request approval」→ 等 GitHub 審核（數天）
3. 審核通過 → 個人 Sponsors 頁自動上線
4. 付款週期：GitHub 每月 22 日自動付款到 Stripe → 澳門銀行
```

### ⚠️ 常見坑

| 坑 | 說明 |
|----|------|
| fiscal host 選錯 | 註冊時選了就不能改，必須聯繫 GitHub 支持才能切換 |
| 身份信息不一致 | GitHub/Stripe/銀行三方姓名地址必須一致，否則審核卡住 |
| 未開 2FA | GitHub 強制要求，先開再申請 |
| W-8BEN 遺漏 | 不交稅表不會收到付款 |
| 銀行不在列表 | Stripe 搜索不到就換銀行，不要硬填 |

## 四、落地步驟

### 1. 建立 FUNDING.yml（GitHub 贊助按鈕收斂所有通道）

```yaml
# .github/FUNDING.yml
github: [Wahero]                                    # GitHub Sponsors 頁（全球，0%）
custom:
  - 'https://afdian.com/a/你的愛發電ID'              # 愛發電（大陸，支付寶/微信）
  - 'https://ko-fi.com/你的Ko-fiID'                 # Ko-fi（全球備援，0% 平台費）
```

保存後 repo 首頁右側自動出現 **Sponsor** 按鈕，下拉列出所有通道。

### 2. README 打賞區（大陸直接掃碼）

```markdown
## ☕ 支持這個項目
維護這個項目需要時間與咖啡 ☕
- 🌍 全球：點擊右上角 **Sponsor**（GitHub Sponsors，0% 平台費）
- 🇨🇳 大陸：掃碼贊助，直接入帳（0% 手續費）

| 支付寶 | 微信 |
|--------|------|
| ![alipay](docs/images/alipay-qr.png) | ![wechat](docs/images/wechat-qr.png) |
```

> 收款碼圖片用 GitHub 直鏈即可（無需伺服器）。注意個人收款碼的單筆限額與風控規則。

### 3. 許可證檔次與回饋（提高贊助意願）

| 檔次 | 金額 | 回饋 |
|------|------|------|
| ☕ 請喝咖啡 | $3 / ¥20 | 無 |
| ⭐ 支持者 | $10 / ¥68 | 鳴謝名單（README）|
| 🚀 贊助者 | $25 / ¥168 | 鳴謝 + 優先功能建議 |

## 五、可選進階（都非 0%，僅備選）

| 方案 | 費率 | 適用 |
|------|------|------|
| **愛發電會員制** | 6%+1% | 想要月付會員、內容分發、粉絲互動 |
| **Stripe Payment Link**（自建頁）| 2.9%+$0.3 | 有香港/海外實體時，最靈活 |
| **Airwallex/WorldFirst 收款** | 0.3-1% | 無 Stripe 時把 Ko-fi/PayPal 收入結匯入支付寶 |
| **Patreon** | 8-12% | 內容創作者，非開源打賞首選 |

## 六、決策清單

1. **是否願意辦澳門 Stripe**？→ ✅ 已有證書：Sponsors 0% 全球通道直接打通；資金結匯入支付寶/微信（有匯兌成本）或留澳門帳戶
2. **大陸通道用收款碼（0%）還是愛發電（6%+1% 但有功能）**？→ 純打賞用收款碼；想要會員/留言用愛發電
3. **鳴謝名單**是否公開？（README 列贊助者，個人隱私考量）
